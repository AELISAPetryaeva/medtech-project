# MedTech Project: Digital Biosensor

## О проекте

Исследование применения компьютерного зрения для анализа биомаркеров.

## Моя роль

- Автор концепции
- Проработка архитектуры данных, разметка и настройка пайплайна обработки
- Разработка прототипа интерфейса (Streamlit)

## Текущий статус

Проект на этапе активной разработки.
Код и данные являются закрытой разработкой до оформления прав на интеллектуальную собственность.

## Технический стек

- Python
- Streamlit
- Git
